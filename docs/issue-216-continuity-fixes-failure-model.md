# Continuity failure model (written before fixes)

Baseline: 627e6627e03512f5314e621471eeb6bc50ffadfa. Earlier independent count-only evidence is retained in /tmp/issue216-continuity-review{,-v2,-v3,-v4}; no production or provider request is needed.

1. Current authenticated owner has a stable scope in room B; a saved document came from now-revoked room A. Explicit delete in B must succeed under current write authorization, expectedVersion, epoch and idempotency. Reads of revoked A, automatic rewrites/restores, stale-version deletion and revoked current write must still reject. A mixed mutation must not acquire a blanket provenance bypass.
2. A complete ten-segment human source has unseen tail facts. The first two-segment window yields a nonempty, structurally valid proposal rejected by verification. Reject that proposal without terminating unread tail. Advance the cursor, schedule only unseen segments, bound total jobs, and terminate after the final rejected window. No unverified document may be stored. Replay/stale workers and forget must not revive evidence.
3. Native pre-activation rollback sees zero stable documents/moves/segments after stable-scope forget. The retained epoch/forgotten_at fence is activation and must block rollback. Empty unactivated schema must still roll back; failure must leave marker13, scope fence and data unchanged. Check both epoch and forgotten_at independently.
4. Forget can commit after inventory SQL, after context assembly, during event/budget waits or between provider retries. Capture scope epochs before loading, reject invalidated snapshots, and revalidate current authorization + epochs at each actual model-attempt admission, serialized with forget in a short database transaction. No database lock may span provider I/O. Calls admitted before forget cannot be unsent; subsequent attempts must not admit the stale snapshot. Include normal, revocation, stale epoch, retries, cancellation, no-memory and foreign-scope controls. Do not log bodies or tokens. No claim of real-provider cancellation.
