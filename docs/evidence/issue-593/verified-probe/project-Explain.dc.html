FlashAttention：把注意力搬进片上 SRAM

标准注意力把 N×N 的分数矩阵写回高带宽内存（HBM）再读回；FlashAttention 对 Q 分块，一次一块地流式计算 softmax 并累积输出，让大矩阵从不完整落到 HBM。省下来的是显存读写，不是算术量。

来源：Dao, Fu, Ermon, Rudra & Ré · FlashAttention: Fast and Memory-Efficient Exact Attention with IO-Awareness · 2022（含 v2/论文修订版要点）

01 · 问题

瓶颈在显存往返，不在 FLOPs

GPU 的 SRAM 带宽和 HBM 带宽相差一到两个数量级。标准实现每一步都要把中间结果写进 HBM：分数矩阵 S = QKᵀ（N×N）、softmax 矩阵 P、输出 O，再加反向传播缓存的 S 与 P。序列越长，这些读写越主导运行时间；显存占用也随 N² 增长。

标准注意力 · HBM 读写 Θ(N·d + N²) S 与 P 各写出、再读回一遍，即 4N² 量级的元素搬运
FlashAttention · HBM 读写 Θ(N²·d²·M⁻¹) 只读写 Q、K、V 与 O；中间量留在 SRAM（M 为 SRAM 容量）
额外计算 ≈ 0 渐近 分块重算带来常数级额外 FLOPs，远小于省下的访存时间

N 为序列长度，d 为头维度（v1 论文按 M ≪ N·d 的常见情形给阶数）。

02 · 机制

分块流式 softmax：一个 Q 块走完全部 K/V

关键在于 softmax 不需要先见到整行分数就能算。在线 softmax只用两个游标——行最大值 m 与指数和 ℓ——遇到新块时修正旧值、吸收新值，于是 O 可以在分块之间保持为 O = diag(ℓ)⁻¹ · Õ 的形式逐步累积。

STEP 1 — 装入 把 Q 的一个块放进 SRAM。K、V 按更小的块顺序读入，每一对 Kⱼ、Vⱼ 只与当前 Q 块相乘后即被丢弃。 for j in blocks(K, V): load Kⱼ, Vⱼ
STEP 2 — 打分 在 SRAM 中算 Sᵢⱼ = Qᵢ Kⱼᵀ（乘缩放 1/√d，先减一个安全常数以免溢出）。这个块只活在片上，从不写出。 Sᵢⱼ = Qᵢ Kⱼᵀ · scale
STEP 3 — 在线更新 用块内最大值与当前 m 比较得到新 m；旧累积量乘 e^(m_old − m_new) 缩小，再并入本块的 exp 与和。ℓ 同步更新。 m′ = max(m, rowmax(Sᵢⱼ))
STEP 4 — 累积与写回 Õ += e^(m_old − m′) · Õ_old + P̃ᵢⱼ Vⱼ。全部 K/V 块走完后，只把 O = diag(ℓ)⁻¹ Õ 写回 HBM。 O = diag(ℓ)⁻¹ · Õ
在线 softmax 递推（单个 Q 块内，逐 K/V 块）
m′ = max(m, rowmax(Sᵢⱼ)) ℓ′ = e^(m − m′) · ℓ + rowsum(e^(Sᵢⱼ − m′)) Õ′ = e^(m − m′) · Õ + e^(Sᵢⱼ − m′) · Vⱼ

03 · 反向

不存 N×N 矩阵，重算分块

反向传播需要 softmax 矩阵的梯度。FlashAttention 在前向只保存输出 O 与每行的 (m, ℓ)；反向时重新载入 Q、K、V 块，在 SRAM 里重算出 S 和 P，顺手得到 dQ、dK、dV。存储从 Θ(N²) 降到 Θ(N)，代价是一次额外的分块前向计算。

前向只存 O、m、ℓ 反向逐块重算 Sᵢⱼ dQ = Σⱼ dSᵢⱼ Kⱼᵀ · scale dKⱼ += dSᵢⱼᵀ Qᵢ · scale dVⱼ += Pᵢⱼᵀ dOᵢ

04 · 边界

它换掉的是 IO，不是复杂度下界

机制上的限制
  • 仍是 精确注意力：结果与标准 softmax 注意力数值等价（浮点上差在舍入误差量级）。
  • FLOPs 仍是 O(N²·d)，长序列下算力本身没减少。
  • v1 的 SRAM 用量随头维度 d 增长，头维度很大时 SRAM 会溢出到 HBM；v2 改为只沿 K/V 并行、减少非矩阵乘运算以改善这一点。
  • 线程块间同步仍是 O(N²·d²·M⁻¹)。
工程与比较上的限制
  • 收益系数取决于硬件（SRAM 大小、HBM 带宽、张量核利用率）与序列长度、块大小选择。
  • 对比 近似注意力（稀疏、线性、低秩）：FlashAttention 不损失精度，但也不提供线性时间的 N 依赖。
  • 它解决的是「固定数学下的访存效率」，不替代更好的注意力结构本身。
