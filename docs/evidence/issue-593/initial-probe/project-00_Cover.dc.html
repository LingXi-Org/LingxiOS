FlashAttention

不改变 Attention 的数学结果，只改变它访问显存的顺序——把本应写回显存、再读回来的巨大中间矩阵，永远留在 GPU 片上。

IO 感知算法 分块 · 在线 softmax 精确、近似无关
标准实现 S = Q·Kᵀ
P = softmax(S)
O = P·V S、P 尺寸 N×N，都需写入显存
FlashAttention for K, V 块：
　S̃ → 更新 m, ℓ → O
输出 O、ℓ 最终写出 N×N 矩阵从不落到显存
