# Same-generation public outcome declaration

Written before implementation. Only generic code and synthetic requests belong in this candidate.

- An auto-delivery request truthfully reports unavailable work, but the runtime infers satisfied from the absence of native gaps. Explicit v2 producers must return a terminal declaration in the same generation; absence must never fall back to satisfied.
- A declaration becomes independent verification or overrides pending/failed actions, authorization, current request versions, resources, artifacts or cancellation. It is model-authored data and can only constrain completion alongside existing authoritative checks.
- Every ordinary answer pays for a second semantic judge, or partial/blocked answers are rewritten without an actual repair finding. Ordinary answers and honest limitations each require one generation and no additional review by default.
- Status, gaps or framing are malformed, duplicated, truncated, oversized or contradictory. The terminal v2 object has exact ordered commentary, answer, outcome fields; outcome has exact status/gaps fields, bounded string lengths/count and wire size, satisfied has no gaps, partial/blocked require gaps. Rejections use bounded existing protocol correction and never repeat effects merely to repair formatting.
- Metadata buffers the entire answer, leaks into public text or private provider reasoning, or changes the public-text reader schema. Only commentary and answer stream immediately; bounded outcome metadata follows the answer and is never published as text.
- A tool-only response is rejected for lacking an answer/declaration, or a tool-turn declaration settles the run early. No-content native tool calls remain legal; text-bearing tool turns use outcome:null. Only a final no-tool turn requires an outcome object.
- Old v1 producers silently accept the new field or change their replay fingerprint. v1 remains exact and unchanged; v2 is explicit, has a distinct provider fingerprint and behavior binding, and cannot resume a v1 binding.
- Correct Unicode, escaping, ordinary quotation or conditional text gets classified by wording. No natural-language classifier or substring-based completion inference is introduced. Gap text is public model-declared remaining work, not private reasoning or independent semantic proof; authoritative observed facts remain mandatory.
- A cancellation between answer and metadata becomes an accepted answer, or invalid metadata drops metered usage. Preserve cancellation and existing accounting/protocol diagnostics.

Qualification: streaming synthetic HTTP provider + actual driver, runtime one-generation terminal behavior, and existing control-plane completion checks. No credentials, private cases, production operations or paid provider calls.
